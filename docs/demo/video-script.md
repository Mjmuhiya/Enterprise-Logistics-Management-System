# LogiFlow Enterprise — 3–5 Minute Demo Script

## 1. Business problem — 30 seconds
Introduce LogiFlow as a logistics platform for shipment creation, tracking, fleet operations, warehouses, invoicing and analytics.

## 2. Design thinking — 30 seconds
Show the README Design Thinking flow: Empathise → Define → Ideate → Prototype → Test. Explain how user needs become requirements.

## 3. Architecture — 45 seconds
Show the architecture diagram. Explain the browser/client, Next.js frontend, FastAPI REST API, JWT/RBAC security and PostgreSQL persistence boundary.

## 4. Authentication — 45 seconds
Demonstrate registration and login. Explain password hashing, access tokens and role-based authorization.

## 5. Shipment lifecycle — 60 seconds
Create a shipment and demonstrate the lifecycle: Created → Assigned → Picked Up → In Transit → Out for Delivery → Delivered. Attempt an invalid transition to demonstrate domain validation.

## 6. Testing & CI — 30 seconds
Show the Pytest integration tests and GitHub Actions workflow. Explain unit/integration/API testing and requirement traceability.

## 7. SDLC conclusion — 30 seconds
Connect the implementation back to requirements, architecture, coding, testing, deployment and maintenance. Highlight evidence in GitHub commits, diagrams, tests and CI.

## Evidence checklist
- GitHub repository and branches
- README and Mermaid diagrams
- Database schema
- API endpoints
- Automated tests
- CI workflow
- Frontend dashboard
- Pull requests and commit history
